# InfoFluxes 2

A simple site: categories, sub-categories, articles. Built fresh on Laravel with a Filament admin.

- Start it: double-click `start.bat`, then open http://localhost:8001/admin
- Main language: English. More languages are switched on in `config/infofluxes.php`.
- The old project (D:\xampp\htdocs\infofluxes) is kept untouched as a backup.
- Steps: 1 setup (done), 2 categories (done), 3 articles (done), 4 public site (done), 5 users and comments (done), 6 AI import (done), 7 move the old categories.
